# Waste Image Classification System - Deep Learning Major Project

This project is a Deep Learning-based web application built to classify waste items into different categories to promote recycling and proper waste management.

## 🚀 Features
- **Custom Dataset Organization:** Uses structured train and validation datasets for image classification.
- **CNN Model Training:** Built using TensorFlow/Keras with data augmentation, dropout, and custom layers.
- **Model Evaluation:** Generates training/validation accuracy and loss graphs, along with a saved `.keras` model.
- **Interactive UI:** Built using **Gradio** so users can easily upload an image and get instant predictions with confidence scores.

## 🛠️ Tech Stack
- Python
- TensorFlow / Keras
- Gradio
- Matplotlib / NumPy / Pandas
